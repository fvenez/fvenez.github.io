ZeusAI is an AI system trained to play the board game [7 Wonders Duel](https://boardgamegeek.com/boardgame/173346/7-wonders-duel). It is loosely based on [AlphaZero](https://www.science.org/doi/10.1126/science.aar6404), combining a neural network which evaluates the board position and a Monte Carlo Tree Search which selects the moves.

I worked on this project with [Giovanni Paolini](https://www.giovannipaolini.org/), [Lorenzo Moreschini](https://www.linkedin.com/in/lorenzo-moreschini/) and [Alessandro Iraci](https://sites.google.com/view/iraci/).

We presented ZeusAI at the [Conference on Games 2024](https://2024.ieee-cog.org/) (☞ [Conference paper](http://doi.org/10.1109/CoG60054.2024.10645555)). A longer more technical paper is currently under review.
